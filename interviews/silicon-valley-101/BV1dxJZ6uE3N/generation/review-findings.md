# 来源与教学质量审查

审查对象为本期 `chapter-*-resume1.json`。已对照 `sources/editorial-checks.md`、两份 `digest-*.md` 和 `accepted-blueprint.json`；下述路径以每章 JSON 根对象为起点。这里只提出供 Argon 整篇改稿使用的要求，不直接改写正文。

## 整篇改稿规则

1. 保留嘉宾经历、任务条件和推理转折。通过“许华哲测试时”“王晟认为”等正常归属说明来源，不在每个段落后加免责声明。
2. 避免每小节都用“为什么……？”开头；前段已经提出的问题，下一段直接回答。人物全职称、Benchmark、Computer Use、后训练、CoT 等只在首次出现时定义，后文使用统一简称。
3. 本章小结可以复习内容；正文、表格、两种框和配图读图不要逐字重复同一结论。框用于机制、定义或具体易错点，表格用于有用的比较。
4. 删除“范式转换”“分数的表面繁荣”“陷入泥潭”“烧钱状态”“显然”“全部弄乱”等渲染语，按具体变化写。不要把嘉宾的观点强化成全行业定论。
5. 接受蓝图已经压缩的新闻名单和账单故事，不要在整篇润色中恢复。主线是任务、反馈与执行条件。

## 第 7 章
