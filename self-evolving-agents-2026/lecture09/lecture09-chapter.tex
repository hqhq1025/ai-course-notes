\section{下午场 Panel：主动 Agent、AGI 与产业落地}

下午场 Panel 由马骁腾、刘卫文、王鸿儒等嘉宾继续讨论经验智能、能力外部化和 Agent 理论，并邀请产业实践者从产品与创业角度补充。讨论的核心不再是单个算法，而是何时可以把一个持续运行的 Agent 交给真实用户。

\subsection{从 reactive interaction 到 proactive interaction}

当前大多数系统等待用户给出明确任务，再在既定 context 中完成；主动 Agent 则需要发现信息缺口、预测未来后果、选择合适时机提醒或行动。主动性带来更高价值，也把错误成本从“回答不好”升级为“做了不该做的事”。

\begin{importantbox}{主动性的三项前置能力}
系统需要维护长期目标，理解当前环境状态，并估计行动的未来影响。缺少任何一项，主动行为都可能退化为频繁打扰、错误自动化或越权执行。
\end{importantbox}

\subsection{AGI 是否已经到来：定义比时间预测更重要}

嘉宾没有给出统一时间表，但提出了更可操作的判断标准：系统能否面对边界模糊的问题，主动发现未知、定义问题、分解问题，并在没有完整人工脚手架时持续探索。按这个标准，当前 Agent 在垂直任务上很强，却仍高度依赖人提供目标、context、harness 和 verifier。

\begin{knowledgebox}{“知道自己不知道”只是起点}
AGI 讨论中反复出现 knowledge boundary。真正困难的不只是识别未知，还要提出可验证问题、选择获取信息的行动，并在新证据到来后更新原有判断。这正好连接 causal exploration、tool use 和 self-evolution。
\end{knowledgebox}

\subsection{短期形态：垂直 Agent 的联邦}

Panel 认为未来数年更可能出现大量专业 Agent，而不是单一万能体。代码、数据分析、科研、个人助理等垂直系统通过 MCP、skills 或服务接口互相调用，形成类似多细胞系统的联合能力。

这种架构的关键不是接口数量，而是可信委托：调用方必须知道对方能力范围、数据权限、失败模式和成本；被调用 Agent 需要返回可验证结果与 provenance。否则多 Agent 只会放大错误传播。

\begin{warningbox}{Agent federation 的系统性风险}
一个 Agent 的错误 observation 可能成为另一个 Agent 的输入，局部权限还可能组合成超出任何单体授权的全局能力。联邦系统需要端到端审计、最小权限、预算限制和跨 Agent 的责任链。
\end{warningbox}

\subsection{个性化产品：长期价值来自 experience loop}

产业嘉宾强调，用户不会为抽象的“自进化”付费，而会为持续减少重复沟通、越来越理解工作方式和能主动完成准备工作的产品付费。因此个性化闭环必须落到可观察指标：任务完成时间、纠错次数、用户采纳率和长期留存，而不是只展示记忆数量。

\begin{importantbox}{Personal Agent 的产品闭环}
用户交互产生经验；系统判断哪些经验值得持久化；memory 或 adapter 更新；下一次任务表现变化；用户纠正又成为新的反馈。每一步都需要可解释入口，尤其是“系统为什么记住这件事”。
\end{importantbox}

\subsection{研究原型到生产系统的缺口}

研究 benchmark 通常有明确任务边界和重置条件，真实产品却面对并发用户、隐私、费用、延迟、模型升级和不可逆副作用。自进化机制进入生产前，至少要解决四个问题：更新隔离、离线回放、灰度发布和回滚。

\begin{enumerate}
    \item \textbf{更新隔离}：一个用户或任务的错误经验不能污染全局模型；
    \item \textbf{离线回放}：新 memory、adapter 或 harness 必须在历史任务上回归；
    \item \textbf{灰度发布}：只对小流量启用，并监控能力与安全指标；
    \item \textbf{回滚}：保留更新前状态，出现行为漂移时能快速恢复。
\end{enumerate}

\subsection{自进化系统如何接受治理}

传统软件发布的是固定版本，自进化 Agent 的行为分布会在部署后变化，因此治理对象必须从“模型文件”扩展到完整学习过程。需要记录经验来源、更新规则、评估集、审批者和生效范围。

\begin{warningbox}{不能让用户成为无意识训练数据}
产品应明确说明哪些交互只用于当前会话、哪些进入个人记忆、哪些可能用于全局改进。默认收集一切不仅带来隐私风险，也会把临时情绪、错误输入和敏感内容固化为长期行为。
\end{warningbox}

\subsection{本章小结}

下午场 Panel 将 self-evolving Agent 拉回现实：主动性需要目标、状态和后果预测；AGI 更像主动发现与解决未知的能力，而非某个 benchmark 阈值；近期产品形态可能是垂直 Agent 联邦与个人 Agent。真正可持续的产业落地依赖经验治理、可信委托、灰度更新和用户可控的记忆机制。
