# Self-Evolving Agents 2026 课程生成计划

## 范围决策

- 课程采用九讲结构：七场主题报告 + 两场 Panel。
- P1、P7 仅为开场，共 197 秒，不单独生成薄讲义；其主持信息和议程背景并入课程导读与相邻讲次。
- 每讲单独生成 `.tex` / `.pdf`，最终再合并为一册课程 PDF。
- Panel 不按逐字会议纪要写作，而按问题链、主要立场、分歧、工程判断和开放问题重构为讨论课。

## 最终结果

- 单册课程 PDF：`self-evolving-agents-2026-notes.pdf`，71 页。
- 九个教学单元均保存公开视频、16 kHz 音频、Whisper SRT/TXT/JSON、manifest 与 teacher-voice ledger。
- 课程正文包含 11 个 section、61 个 subsection、44 个教学盒和 95 个图位。
- 双遍 XeLaTeX、渲染视觉 QA 与 `git diff --check` 通过。
- 展开版课程审计为 `⭐⭐`：95 个图位导致 prose/figure 为 172，低于 CS336-style 的 260 启发式；本课程按专题综述保留较高图密度，不标记为 `⭐⭐⭐`。

## 验收标准

- 每讲有 source manifest、coverage matrix、teacher-voice ledger 和明确的图像来源时间。
- 报告讲义覆盖可辨识的全部教学幻灯片；Panel 覆盖全部主要问题链和关键分歧。
- 每讲双遍 XeLaTeX 编译，无硬错误，并通过 `check_quality.sh`、`check_note_coverage.py` 和 `render_pdf_qa.py`。
- 视觉 QA 检查课件可读性、裁切、空白页、URL 溢出、孤立图注和图文比例。
- 课程级 README、总 PDF 和仓库跟踪文件保持一致。
