\section{迈向经验智能：从 Context Engineering 到 Context Learning}

马骁腾把下一阶段的 Agent 能力称为 \textbf{Experiential Intelligence}：系统不只在单次请求中拼装 context，而是从长期交互中学习“什么信息对这个用户、这个任务和这个时刻最有用”。这要求把 context engineering 从人工规则升级为可训练、可评估、可持续服务的 context learning。

\sourcefigure{0.93}{lecture06/slides-images/slide-002-00030s.jpg}{经验智能：让系统从长期交互中获得个性化能力}{00:00:30--00:01:00}

\subsection{为什么只扩模型规模不够}

模型规模继续增长，但每个用户真正需要的是稳定的个人偏好、项目状态和历史经验。通用参数无法及时吸收私有且不断变化的信息；把全部历史塞进 prompt 又会带来上下文成本、噪声和隐私问题。

\sourcefigure{0.93}{lecture06/slides-images/slide-003-00060s.jpg}{模型规模与个体经验规模并非同一条扩展曲线}{00:01:00--00:01:45}

\sourcefigure{0.93}{lecture06/slides-images/slide-004-00105s.jpg}{AI 的“下半场”从通用能力转向经验与个性化}{00:01:45--00:02:00}

\begin{importantbox}{Context Learning 的对象}
学习的不是一段固定 prompt，而是“如何从记忆、环境、用户状态和工具结果中选择、压缩、排序并更新 context”的策略。它决定哪些经验进入当前推理，哪些写回长期状态，哪些应该遗忘。
\end{importantbox}

\subsection{LoRA as Memory：参数高效的经验载体}

报告探索把 LoRA adapter 视为可训练记忆。相比完整微调，LoRA 只学习低秩增量

$$
W'=W+BA,\qquad \mathrm{rank}(BA)=r\ll d,
$$

其中基础权重 $W$ 保持冻结，$A,B$ 存储特定经验。多个用户或任务可以拥有独立 adapter，服务时按需加载。

\sourcefigure{0.92}{lecture06/slides-images/slide-014-00510s.jpg}{Context engineering 与 context learning 的边界}{00:08:30--00:11:30}

\sourcefigure{0.92}{lecture06/slides-images/slide-015-00690s.jpg}{LoRA as Memory：用参数增量承载长期经验}{00:11:30--00:13:15}

\begin{warningbox}{参数记忆不是万能数据库}
LoRA 适合沉淀行为偏好和可泛化模式，不适合精确保存需要删除、审计或逐条引用的事实。事实记录仍应保留在外部 memory store；参数更新与可检索记忆需要协同，而不是互相替代。
\end{warningbox}

\subsection{从离线 adapter 到在线 Context Learning}

个性化系统要处理连续到来的少量样本，要求训练稳定、低成本并能避免灾难性遗忘。报告通过 LoRA 初始化、rank/scale sweep 和评测协议研究经验如何快速写入，同时保持基础能力。

\sourcefigure{0.93}{lecture06/slides-images/slide-018-01050s.jpg}{不同 LoRA 初始化对稳定性和收敛的影响}{00:17:30--00:19:00}

\begin{knowledgebox}{经验写入需要三道门}
第一道是价值判断：这次交互是否包含未来可复用信息；第二道是归因：应该更新用户偏好、任务技能还是环境知识；第三道是验证：更新后是否改善目标任务且没有破坏旧能力。
\end{knowledgebox}

\subsection{MiNT：训练与服务百万级个性化模型}

当每个用户都可能拥有 adapter，问题从算法转向系统：如何调度训练、缓存热模型、合并 batch、管理版本与回滚。MiNT 类基础设施把 adapter 训练和 serving 抽象成服务，使大量小模型共享基础权重与 GPU。

\subsection{从研究系统到 Personal Agent}

最终目标是把记忆、个性化模型和环境工具组合成 Personal Agent。个人智能不只表现为“记得名字”，而是能长期理解目标、协作方式、风险偏好和正在进行的项目，并让这些经验跨任务复用。

\sourcefigure{0.93}{lecture06/slides-images/slide-031-01830s.jpg}{Personal Agent 将 memory、environment 与个性化模型连接起来}{00:30:30--00:32:15}

\begin{warningbox}{个性化必须包含遗忘与授权}
系统应允许用户查看、纠正、删除和冻结经验；敏感信息不能因为被写入 adapter 就失去治理能力。长期学习的产品必须把 consent、retention policy 和模型版本审计作为一等功能。
\end{warningbox}

\subsection{本章小结}

Context Learning 把“给模型什么上下文”变成可学习策略，并用参数高效更新承载可泛化经验。真正可用的经验智能还依赖大规模 adapter 训练与服务、外部可审计记忆，以及明确的写入、验证和遗忘机制。
