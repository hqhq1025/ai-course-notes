\section{Theory of Agent：机器智能的“下半场”}

王鸿儒试图给 Agent 建立统一分析框架。传统语言模型主要优化“看到输入后生成什么文本”，Agent 则必须回答“什么时候需要行动、应该调用什么外部能力、如何维护跨时间状态，以及如何知道自己不知道”。

\subsection{Thinking/Reasoning 与 Doing/Acting}

报告首先区分内部推理和外部行动。Reasoning 改变内部 token state，acting 改变环境并获得新信息。一个系统即使能产生很长的 chain-of-thought，也不一定知道何时应该停止内部推演、转而调用搜索、代码或真实执行。

\sourcefigure{0.93}{lecture08/slides-images/slide-003-00105s.jpg}{人类智能中的 thinking 与 doing 两类过程}{00:01:45--00:02:30}

\sourcefigure{0.93}{lecture08/slides-images/slide-004-00150s.jpg}{ReAct 将 reasoning 与 acting 交错组织}{00:02:30--00:03:15}

\begin{importantbox}{Agent 的核心决策}
Agent 的基本动作不是“输出答案”，而是在内部推理、调用工具、观察环境、向用户提问和终止任务之间选择。工具调用因此是一个具有成本和信息价值的决策问题。
\end{importantbox}

\subsection{知识边界与能力边界}

系统需要区分三种状态：已知且可直接回答、未知但可通过工具获得、未知且当前工具也无法解决。若没有 knowledge boundary，Agent 会在需要检索时幻觉；若没有 capability boundary，又会在无法完成的任务上无限尝试。

\sourcefigure{0.93}{lecture08/slides-images/slide-013-00690s.jpg}{Knowledge Boundary：已知、可获取与不可获取信息}{00:11:30--00:13:00}

\sourcefigure{0.93}{lecture08/slides-images/slide-014-00780s.jpg}{能力边界决定何时调用工具与何时承认失败}{00:13:00--00:14:30}

可以把工具调用写成价值比较：

$$
\mathrm{CallTool}\iff
\mathbb{E}[U\mid \text{tool result}]-C_{\text{tool}}
>\mathbb{E}[U\mid \text{internal answer}],
$$

其中 $U$ 是任务效用，$C_{\text{tool}}$ 包含延迟、金钱、隐私和执行风险。Agent 应学习的是期望净收益，而不是“能用工具就用”。

\subsection{长上下文、RAG、记忆与工具的统一视角}

长上下文、检索增强、长期记忆和工具调用都在扩大模型当下可利用的信息边界，但它们成本结构不同。长上下文直接增加 token；RAG 外部检索文档；memory 保存与用户或任务有关的状态；工具则能读取或改变环境。

\sourcefigure{0.93}{lecture08/slides-images/slide-015-00870s.jpg}{长上下文、RAG、memory 与工具扩展知识边界的方式}{00:14:30--00:15:45}

\sourcefigure{0.93}{lecture08/slides-images/slide-016-00945s.jpg}{统一的 Agent 能力边界与外部资源选择}{00:15:45--00:17:45}

\begin{warningbox}{更多 context 不等于更好决策}
上下文越长，检索噪声和注意力竞争也越大；工具越多，选择错误和协议成本越高。系统必须学习 resource routing，而不是无条件扩展输入。
\end{warningbox}

\subsection{Agentic Post-Training 与统一目标}

若希望模型学会何时思考、何时行动，就需要在包含工具和环境的轨迹上训练。Agentic post-training 不只奖励最终答案，还要处理行动成本、过程约束、信息获取和终止时机。

\subsection{Self-Evolving Agent 的形式化}

报告把自进化写成跨 episode 的状态更新。设 Agent 内部可持久化状态为 $z_t$，单次交互轨迹为 $\tau_t$，评价为 $e_t$，则

$$
z_{t+1}=\mathcal{L}(z_t,\tau_t,e_t),
\qquad
\pi_{t+1}(a\mid s)=\pi(a\mid s,z_{t+1}).
$$

$z$ 可以包含模型参数、memory、skill、tool policy 或 harness。这个定义的关键是更新必须跨任务持续存在，并能在未来行为中被验证。

\sourcefigure{0.93}{lecture08/slides-images/slide-022-01590s.jpg}{Self-evolving Agent 的跨 episode 更新形式}{00:26:30--00:27:15}

\sourcefigure{0.93}{lecture08/slides-images/slide-024-01710s.jpg}{静态世界假设与开放世界中的持续变化}{00:28:30--00:29:15}

\begin{knowledgebox}{理论的价值}
统一框架不一定立刻给出更高 benchmark 分数，但它迫使研究者说明：状态在哪里、工具成本是什么、学习跨越哪个时间尺度、哪些变量能被更新、评估信号来自哪里。没有这些定义，“Agent”“记忆”“自进化”很容易只剩产品标签。
\end{knowledgebox}

\subsection{本章小结}

Theory of Agent 把机器智能的下半场描述为资源与行动决策：模型要认识知识边界，比较内部推理与外部工具的价值，维护跨时间状态，并通过 agentic post-training 学习成本敏感的交互策略。Self-evolution 则是这些持久状态在反馈作用下发生可验证更新。
