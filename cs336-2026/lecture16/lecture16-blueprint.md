# Lecture 16 Blueprint — RLVR

Narrative question: 当 reward 可以自动验证时，怎样把 RL 扩展到数学、代码和 agent tasks，同时避免 GRPO 偏差与系统低效？

1. PPO recap：token actions、terminal reward、KL shaping、GAE。
2. GRPO：group-relative baseline、无 value model、tiny implementation。
3. Objective audit：unbiased baseline、standard-deviation scaling、length normalization。
4. DeepSeek R1：R1-zero、SFT initialization、language consistency、distillation。
5. Kimi K1.5：difficulty filtering、curriculum、length control、RL infra。
6. Qwen3/Qwen3-Coder：thinking fusion、stage composition、agent environments。
7. RLVR systems：rollout bottleneck、variable lengths、train/inference switching。
