# 来源与术语

主来源为月球大叔官网完整逐字稿。嘉宾江鋆晨（Junchen Jiang），主持人月球大叔。YouTube 发布日期为 2026-06-09。说话人由官网按上下文推定，带 † 的短应答不单独引用。片头摘录不重复写作。

已直接读取 LMCache 官方 README、CacheGen 论文摘要（arXiv:2310.07240）、CacheBlend 论文摘要（arXiv:2405.16444）、Google IPv6 部署统计页面；原文保存在本目录。LMCache 提供 KV 缓存跨请求、实例的管理和传输，对接推理引擎。缓存仍绑定生成它的模型及相关计算语义，不能说任何两个模型可直接互换 KV。

KV Cache 是注意力机制中的 key/value 张量，不是传统 key-value 数据库。张量的维数取决于是否显式列出 batch、层、头等维度，不复述“总是三维”的口述为普遍定义。它保存推理中间状态，不自动把知识写进权重，不是人类长期记忆。基础教学可介绍 batch=1 的常规注意力 KV 字节数：2×层数×缓存token数×KV头数×头维度×每元素字节；数字2来自K/V两份。GQA/MQA会改变KV头数，压缩、量化和混合结构会影响实际占用，不需要无限展开模型特例。

精确前缀复用需要相同模型和相同token前缀及兼容的位置/执行配置。CacheBlend 针对重排文档块造成的跨块依赖，选择性重算部分token；不要说任意片段无损直接拼接。CacheGen 是压缩与传输优化，不能承诺所有负载同倍率收益。论文原有测量数字若无条件不引用。prefill处理输入，decode逐步生成；总延迟和总计算是两种量，长输入任务可能prefill占计算大头但非所有请求。

90%输入是代码的例子可作为教学情景；90%算力在prefill，嘉宾紧接着明确无直接统计，改为长输入工作负载下计算占比可能很高。不写缓存节约90%总延迟或总账单。存储涨价为供需判断，“罪魁祸首”是玩笑，不写成公司影响价格的证据。Cerebras、Groq 的IPO/收购口述不作为本书事实基础；只讨论硬件优化与prefill/decode互补。

内部张量能供分析，但不等于直接看懂模型全部想法，优化KV也不保证生成正确。解释和修改记忆属于研究愿景；不把LMCache缓存管理写成已经实现全部自我进化。奖学金与导师经历是个人回忆；理论研究不只证明不可能，安全研究不只限制能力。Conviva 为公司拼写，Ion Stoica 为人名，CDN 是内容分发网络，HDFS是分布式文件系统，Spark是分布式计算系统，二者不混同。

OpenAI兼容接口是请求响应格式的生态惯例，不是官方统一网络协议，不保证所有扩展能力一致。IPv6已有广泛实际部署，不能写成“没成”或“无人采用”；IPv4惯性解释迁移成本即可。OpenAI在2020年前已发布GPT系列，不沿用末段“当时没押注GPT”的说法。行业整合/分离架构共存有条件，不称历史必然淘汰集成系统。

融资、NVIDIA/AMD支持和八个月轮次为节目披露；并不证明独家商业合作、市场唯一或收入。师生联创优势为本团队经验，嘉宾也指出样本小；保持联创平等和技术反对权。博士建议为接触工业界前沿，他明确没有建议退学。30岁建议考虑责任，不能统一成人人冒险。
