前 7 期使用节目官网的完整带时间戳文字；Brandon 这期使用完整音频转写。每期目录中的 `sources/` 保存来源文字，`coverage-matrix.md` 记录口述重点及正文安排。

Argon 负责章节写作和全文编辑，Codex 负责来源核对、机制图、LaTeX 排版及 PDF、网页检查。讲义按问题组织，保留实例、讲者提醒和双方的不同看法，并配有概念图、对照表和重点框。

每期已完成双遍 XeLaTeX 编译、质量与覆盖检查和实际 PDF 视觉检查，记录见各期 `qa/`。PDF 发布在 GitHub Release；仓库保留 LaTeX、配图和来源文字。
