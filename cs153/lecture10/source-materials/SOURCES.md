## Version-handling rule

The classroom used the 2025-era `AI Safety Level` framing. Anthropic's current RSP v3.0 changed terminology and governance details, including capability thresholds and required safeguards. The note preserves the classroom explanation as a historical snapshot, then labels the current framework as later evolution instead of treating the versions as interchangeable.
