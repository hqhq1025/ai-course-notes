# 第 2 讲独立审阅

路径使用 prose.json 的零起始数组索引。

- sections[0].units[4].reading：Harness 编排消息，模型遵循角色语义；OS/沙箱强制具体操作权限，不能保证语言指令优先级。
- sections[0].boxes[1].text：删除混入的印地语。缺少“喵”只说明遵循要求异常，无法据此判断压缩、截断或注意力根因。
- sections[2].equation：集合 S 的候选数量用 |S|；数量乘积需要各维独立可组合的假设。
- sections[2].units[3].reading/after：未规定不等于正式授权高影响动作；失败契约能约束流程，不能保证 Agent 始终遵循。
- sections[3].boxes[0].title：Verifier 不等于形式验证器，改为“验收器的能力边界”。
- sections[3].units[1].after：“向”的 iang 与 ang 可以押江阳韵，不要按字母后缀误判不押韵。
- sections[3].units[3].before：官方材料没有给《季姬击鸡记》赵元任这一归属，删错误作者归属。
- sections[3].units[4].after：有验收器不保证机器能解决所有任务。99%/1% 是讲者估计。
- sections[4].units[2].after：LUCA 指现存生命的最近共同祖先，与人类线粒体母系最近共同祖先不同。
- sections[5].units[2].after：消息传递与集中网关可用于同一代码库不同层，不是必然互斥；探索维度也不天然正交。
- sections[6].units[0].after、boxes[0].text：符号执行案例奖励黑客解释是待检验假说，未定位根因。
- sections[7].units[0].before/reading：明确规格和测试不能保证单一路线收敛；“优秀方案在低概率尾部”和 RL 倾向尽快交卷是课堂分析，非普遍机制定论。
- 通篇：统一术语；保留关键前提，用事实和机制接续段落，删除每页固定提示和反复免责声明。检查 Skill 自动卸载是否有实际资料依据，不写成普遍硬保证。
