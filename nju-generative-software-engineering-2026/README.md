## 文件说明

每讲包含：

- `course.md`：适合仓库和 Markdown 阅读器的图文实录。
- `course.html`：可直接在浏览器打开的单文件正文页面。
- `frames/`：按课堂画面变化截取的全幅画面。
- `transcript.raw.srt`：本地 ASR 原始字幕。
- `transcript.cleaned.srt`：按课堂段落重排并校正明显识别错误的字幕。
- `structured.json`：保留时间、画面、原文和校订文字的结构化数据。

截图由完整课堂录像按右侧教学区域的画面变化检测选取，最终保存全幅画面，
因此老师、黑板、课件、终端和浏览器演示可以在同一时间点对应起来。
