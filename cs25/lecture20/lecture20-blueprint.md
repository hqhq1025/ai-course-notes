# Lecture 20 Rewrite Blueprint

## Source Boundary

- Canonical video: Stanford Online `wwQ1LQA3RCU`, classroom date 2023-10-24.
- Visual spine: 61 selected teaching states in `slides-images/`, each used exactly once.
- Spoken spine: 18 teacher-voice intervals in `lecture20-teacher-voice-ledger.md`.
- Research boundary: MineDojo/MineCLIP, Voyager, Eureka, VIMA, Video PreTraining, RT-2, and RoboCat as presented by October 2023.

## Teaching Sequence

1. **Source audit and active-kitten thesis**
   - Official source, Held-Hein experiment, passive pretraining versus active embodied feedback.
2. **What is a generalist agent?**
   - Open-ended objectives, broad world knowledge, massively multi-task competence.
3. **Three ingredients**
   - Open-ended environment, internet-scale knowledge base, flexible foundation model.
4. **MineDojo and MineCLIP**
   - Minecraft task ecology, creative-task evaluation, internet knowledge, video-language contrastive reward, RL evidence and robustness.
5. **Voyager**
   - Symbolic/code action space, iterative prompting, critic, skill library, retrieval, automatic curriculum, integrated loop, exploration evidence.
6. **Eureka**
   - Environment code as context, reward code generation, RL feedback, reflection, reward evolution, dexterous-task evidence.
7. **Learning from internet-scale video**
   - Representation, reward, inferred action/behavior cloning, Video PreTraining boundary.
8. **Multimodal foundation agents**
   - Interleaved multimodal prompts, VIMA architecture and examples, RT-2 and RoboCat.
9. **总结与延伸**
   - Compare environment, knowledge, model, memory, curriculum, feedback, embodiment, and evaluation.
